# Leafbook 叶书制作器

在 Mac 上做互动电子书的桌面工具：导入图片排成一本会真实翻页的书，
加背景音乐，一键导出**单个 HTML 文件**，发到微信里给客户翻着看。

## 它能做什么（v1.2）

- **新建项目时选页面尺寸**：横版 / 竖版 / 方形，比例 3:4、4:3、16:9、9:16、
  A4 竖版、A4 横版、1:1，外加自定义宽高（px）；每个比例都有推荐像素尺寸，
  比如竖版 1080×1440、A4 竖版 1240×1754、横版 1920×1080、方形 1080×1080。
- **尺寸随时能改**：编辑器右侧「页面尺寸」里改完点「应用尺寸」即可。
  已有图片按完整显示适配，不裁剪、不拉伸。界面顶部会一直显示
  「页面尺寸：1080 × 1920 px · 9:16 竖版」这样的当前尺寸。
- **导入图片成页**：一次选多张 PNG/JPG/WebP，按文件名顺序一页一张；
  页面可上移、下移、删除，可加空白页。
- **导入 PDF 成页**（v1.2 新增）：点「导入 PDF」，PDF 的每一页会被转成
  一张页面图（按完整显示放进当前页面尺寸，不裁剪、不拉伸），
  导入时有逐页进度；解析失败会提示改用图片导入。适合把现成的
  PDF 画册、课件直接变电子书。
- **每页可加文字**：标题 + 正文，显示在页面底部；可单独设本页背景色。
- **背景音乐**：导入一首 MP3/M4A/WAV。微信里读者点「开启音乐」后才播放
  （这是微信的规则），翻页不会中断，循环播放。
- **阅读背景可以改**（v1.1 新增）：读者打开电子书时，书本是摆在一片
  场景上的（就像一本打开的书放在桌上、庭院里）。这个背景在右侧
  「阅读背景」里换，三种来源：
  - **内置场景**：樱花庭院、深色木桌、湖畔晨光、纯色纸纹、夜读，
    点一下缩略图就换；
  - **自定义颜色**：选一个纯色当背景；
  - **导入自己的背景图**：JPG/PNG，导入后会自动虚化、压暗，
    只当氛围，不抢书的内容；不想要了点「移除背景图」回到内置场景。
  换背景时中间预览会立刻变，导出的电子书和预览长得一样：
  棕色皮面书框、纸边、书底下的柔和投影，顶栏是书名 + 音乐按钮，
  底部是圆形翻页箭头和页码。
- **封面模式**（v1.2 新增）：右侧「整本设置」勾选「第一页作为封面」后，
  书籍模式会把第一页单独作封面展示（像真实书的封面那样），
  编辑器预览与导出效果一致。
- **两种看书方式**（制作时预览、导出后都有）：
  - 📖 书籍模式：StPageFlip 真实纸张卷曲翻页，可拖页角；
  - 📱 图文模式：全屏上下滑动逐页看。
- **导出的书更像真书**（v1.2 新增）：翻页时有轻轻的纸声（顶栏 🔊 可关，
  声音是实时合成的，不占文件体积，读者第一次触摸屏幕后才生效）；
  顶栏有 ⛶ 全屏按钮；在电脑上打开还能用键盘 ← → 翻页。
- **导出清晰度可选**（v1.2 新增）：右侧「导出设置」三档——
  高清（JPEG 0.85，长边上限 1700px）、标准（0.75，1400px）、
  小文件（0.6，1100px）。导出前会自动按档位压缩页面图，
  右上角会显示预计导出大小，发微信怕文件太大时选「小文件」。
- **项目存档**：保存为一个 `.leafbook` 文件（图片、音乐都在里面），
  下次打开继续改。
- **导出微信 H5**：生成一个自包含的 `.html`（图片、音乐、翻页效果全在
  这一个文件里，不依赖任何服务器）。

## 怎么用（做一本书）

1. 打开 App → 新建：起名字，选横版/竖版、比例和像素尺寸 → 创建项目。
2. 点左侧「导入图片」选页面图（建议就按项目尺寸出图），或「导入 PDF」
   把现成 PDF 整本转进来。
3. 需要的话逐页加标题/正文，导入背景音乐；想让第一页单独作封面，
   就勾上「第一页作为封面」。
4. 在右侧「阅读背景」里挑一个场景（或导入自己的背景图），
   中间预览区切「书籍翻页 / 图文滑动」检查效果。
5. 点右上角「保存项目」存一个 `.leafbook` 备份。
6. 在「导出设置」里选清晰度（看一眼预计大小），点「导出微信 H5」，
   得到 `项目名.html`。

## 导出后怎么发到微信

单个 HTML 文件不能直接在微信里当链接打开，需要先放到一个网址上：

1. 把导出的文件改名为 `index.html`；
2. 上传到 GitHub 仓库 `leafbook-demo` 根目录（覆盖旧的即可）；
3. 仓库 Settings → Pages → Deploy from a branch → main → /(root)，保存；
4. 等一两分钟，打开 https://hanson-zz.github.io/leafbook-demo/ 就是这本书，
   把链接或二维码发给客户，在微信里点开就能翻页、听音乐。

> 注意：GitHub Pages 在国内网络有时不稳定；正式给客户长期用，
> 建议后续换国内云存储 + 已备案域名，导出文件本身不用改。

## 怎么得到 DMG 安装包

本仓库用 GitHub Actions 在云端 Mac 上打包（本地不需要装任何开发工具）：

1. 打开仓库的 **Actions** 页 → 左侧选 **Build Leafbook DMG**；
2. 点 **Run workflow**（版本号可不改）→ 等约 5–10 分钟跑完；
3. 打开这次运行记录，拉到最下面 **Artifacts**，下载 `Leafbook-DMG-…`；
4. 解压得到 `.dmg`，双击打开，把 Leafbook 拖进「应用程序」。
5. 第一次打开如果被系统拦下，看同包里的 **打不开怎么办.txt**
   （右键点 App → 打开，即可放行）。这是未签名应用的一次性步骤。

## 开发 / 本地运行（给后续维护）

```bash
npm install
npm start     # 本地运行编辑器
npm test      # 逻辑测试：尺寸模块 + 导出 HTML 断言
npm run dist:mac   # 在 Mac 上本地打 DMG（一般用云端 Actions 即可）
```

结构：`src/main.js` 主进程（对话框/文件读写）、`src/preload.js` 安全桥、
`src/renderer.js` + `index.html` + `styles.css` 编辑器界面、
`src/sizes.js` 尺寸/比例预设、`src/backgrounds.js` 阅读背景场景定义
（编辑器预览与导出共用）、`src/quality.js` 导出清晰度预设、
`src/exporter.js` H5 导出模板（编辑器与测试共用）、
`vendor/` 内置 StPageFlip（MIT）与 PDF.js（Apache-2.0，见 vendor/README.md）。

## 已知边界（v1.2）

- 不做图层拖拽编辑；页面图请先在设计软件里做好再导入
  （或整本 PDF 导入后直接用）。
- DMG 未做苹果签名公证，首次打开需右键放行（见上）。
- 微信真机效果（音乐、翻页手感）需发布后在 iPhone / 安卓微信里各验一次。
